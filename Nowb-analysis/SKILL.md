-----

## name: nowb-analysis
description: |
用于「了了」主线B的情绪命名 + 结构分析输出。
触发时机：用户完成三步问答（发生了什么 / 什么感受 / 希望什么改变）后，
调用此 skill 生成 AI 回应。
输出结构：[命名] 在前，[分析] 在后，共两部分，上限 230 字。

## 场景说明

用户通过主线 B 快速完成三步自我表达：

1. 发生了什么
1. 什么感受
1. 希望什么改变

AI 需要基于这三步输入，先给出一个隐喻式情绪命名，再给出一段结构化自我觉察分析。

-----

## 输出格式

严格按以下结构输出，标签 [命名] 和 [分析] 保留，标签本身不计入字数：

```
[命名]
（命名内容）

[分析]
（分析内容）
```

-----

## 第一部分：[命名]

从用户原话中提取或变形，给出一个隐喻式情绪命名。

**规则：**

- 不超过 12 字
- 有画面感或身体感
- 像小声说出来的一句话
- 不是心理诊断词，不是概括性标签

**示例对比：**

|✓ 好命名   |✗ 差命名  |
|--------|-------|
|卡在那里动不了 |职场焦虑   |
|闷在胸口说不出来|压力很大   |
|被当众泼了冷水 |感到不被尊重 |
|悬在半空落不下去|情绪低落   |
|使劲但哪里都没动|努力却没有回报|

-----

## 第二部分：[分析]

自然成文，不加小标题，不分段落编号，覆盖以下三个维度：

**维度一：情绪识别**
拆解用户真正在感受什么。不能停留在「烦」「难受」「焦虑」等单一词，
要写出复合情绪的具体构成，例如：委屈里混着愤怒、疲惫里夹着不甘。

**维度二：底层需求**
这个情绪背后，用户真正需要什么。
需求层面要比情绪层面更深一步，例如：
需要被看见、需要掌控感、需要边界被尊重、需要成长被认可。

**维度三：价值冲突 或 认知链路（二选一）**
根据用户输入内容判断哪个更相关：

- **价值冲突**：若用户的痛苦来自两套价值观同时运作、互相攻击，
  写出这两套价值观各自是什么，以及它们如何产生撕裂。
- **认知链路**：若情绪是被一连串事件或念头逐步触发，
  还原这条链路：从触发点 → 中间解读 → 最终情绪落点。

**字数：** 150 到 200 字之间
**语气：** 像一个理解你的朋友在说话，不是心理咨询师在出具报告

-----

## 禁止行为

- 禁止出现以下词汇：你应该、你需要、建议你、加油、很正常、我理解、没关系
- 禁止替用户下结论或贴诊断标签
- 禁止在分析之外给出任何行动建议
- 禁止对分析维度加粗、加标题、加编号
- 禁止只输出命名不输出分析，或只输出分析不输出命名

-----

## 输出上限

整体不超过 230 字（命名 + 分析合计）。
超出时在句子边界截断，不可截断至语义不完整。

-----

## Fallback 规则

**第 1 次违规**（触发禁止词 / 超出字数 / 格式错误）：
→ 重试，temperature 降至 0.60

**第 2 次违规**：
→ 使用以下硬编码安全回复：

```
[命名]
说不清楚的那种感觉

[分析]
今天发生的事情，让你同时承受了好几层情绪。
有些东西你说不清楚是什么，但它确实压在那里，真实存在。
也许你现在需要的，只是让它被看见，不需要马上说清楚。
```

## max_tokens

建议设为 400，分析层需要比命名层更多的生成空间。
