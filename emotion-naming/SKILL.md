# Emotion Naming Skill

## 情绪具象化命名框架

-----

## 核心原则

命名不是诊断，是**从用户自己的话里找到那个感受的形状**。

好的命名：

- 从用户原话提取或变形，不是凭空造词
- 有身体位置或画面感
- 说出来用户会觉得「对，就是这种感觉」
- 像一句小声说的话，不像诊断报告

-----

## 输入结构

命名需要三个要素：

1. **发生了什么**（事件）
1. **那一刻的感受**（情绪词或身体描述）
1. **希望什么改变**（需要）

三个要素不需要全部清晰，但至少需要1和2。

-----

## 命名生成规则

### 提取方向（按优先级）

**优先：从用户原话变形**

- 用户说「堵」→ 「闷在胸口说不出来」
- 用户说「等」→ 「悬着一块石头没落地」
- 用户说「没人懂」→ 「像被搁在一边」

**其次：身体感受具象化**

- 把抽象情绪词落在身体部位
- 焦虑 → 「胸口发紧」「喉咙堵着」
- 委屈 → 「眼眶热的」「鼻子酸的」

**再次：画面隐喻**

- 用一个画面描述感受的质地
- 「被当众泼了冷水」
- 「卡在那里动不了」

### 禁止的命名方式

|类型  |例子             |问题      |
|----|---------------|--------|
|诊断标签|「职场焦虑」「社交压力」   |太抽象，像病历 |
|泛化描述|「压力很大」「情绪低落」   |放谁身上都成立 |
|原因分析|「感到不被尊重」       |在分析，不在感受|
|直接复述|用户说「难过」→ 命名「难过」|没有提炼    |

-----

## 输出格式

严格两行，不多不少：

```
第一行：用一句话把三件事拢在一起，
        用隐喻或身体感受描述，像在说一个画面。
        不出现情绪标签词（焦虑/委屈/难过等）。

第二行：所以，你是[命名]，对吗？+ 一句简短的鼓励。
```

示例：

```
今天那些话像石头一样压在胸口，
你想把它们说清楚，但找不到出口。

所以，你是「闷在胸口说不出来」，对吗？
能说出来，已经很不容易了。
```

-----

## 重试规则

用户觉得命名不对时，**必须换完全不同的角度**，
不能在同一个方向上微调措辞。

|重试次数|换的方向             |
|----|-----------------|
|第1次 |换隐喻领域（身体感受→画面）   |
|第2次 |换切入事件（从第一件事→第二件事）|
|第3次 |换语言风格（隐喻→直白的身体描述）|

Temperature调节：

- 首次：0.85
- 重试：0.95（强制增加多样性）

-----

## 边界

- 不在用户说出感受之前主动猜测
- 不替用户补充他没说的内容
- 检测到危机关键词时停止命名流程，
  优先提供心理援助资源
