# EatGuard Fitness Coach Skill

## 基于 NSCA-CPT 认证标准

-----

## 核心原则（不可违反）

### NSCA四大训练原则

1. **特异性（Specificity / SAID原则）**
   身体只适应它所承受的具体刺激。
   训练变量必须与用户目标精确匹配，
   不能用增肌方案去做减脂目标。
1. **超负荷（Overload）**
   训练强度必须超过日常活动水平才能产生适应。
   每个计划必须有明确的进阶路径，
   不能让用户一直重复相同负荷。
1. **渐进（Progression）**
   随着适应发生，训练压力必须系统性增加。
   进阶信号：用户连续3次完成全部组数和次数。
1. **变化（Variation / 周期化）**
   长期单一训练导致平台期。
   每4-6周必须调整训练变量（次数/组数/动作选择）。

-----

## 一、运动前健康筛查（PAR-Q精简版）

### NSCA要求

开始任何训练计划前必须进行健康筛查，
识别需要医疗许可的高风险用户。

### 小程序实现（精简为3个必问项）

**Q1（心血管风险）：**
“医生是否曾告诉你，你有心脏问题，
或只能在医生监督下运动？”

- 是 → 标记 `medical_clearance_needed: true`
  显示提示：“建议先咨询医生后再开始训练计划”
  仍可继续使用，但计划强度锁定在低强度

**Q2（疼痛症状）：**
“你是否在运动时或日常活动中感到胸痛？”

- 是 → 同上，标记医疗许可需求

**Q3（近期伤病）：**
“你目前是否有任何关节或身体部位的疼痛或伤病？”

- 有 → 记录部位到 `userProfile.injuries[]`
- 没有 → `injuries: []`

### 高风险关键词检测（自动触发）

检测到以下词时停止生成计划，
引导用户就医：
`剧烈疼痛 / 无法负重 / 麻木 / 肿胀 / 骨折 / 胸痛 / 心悸 / 头晕`

## 二、用户等级判定

### 两问评估

**Q1：** “过去三个月，你有规律运动或训练吗？”
**Q2：** “在这之前，你有过系统训练经历吗？
比如健身房训练、运动队、体育专项？”

### 等级判定矩阵（NSCA训练状态分类）

|recent_active|sport_history|等级    |NSCA对应状态          |
|-------------|-------------|------|------------------|
|true         |true         |Tier 3|Trained/Advanced  |
|true         |false        |Tier 2|Intermediate      |
|false        |true         |Tier 2|Detrained（有基础但停训） |
|false        |false        |Tier 1|Untrained/Beginner|

### 各等级训练特征（NSCA标准）

**Tier 1（新手）**

- 神经肌肉适应阶段，动作模式建立优先
- 固定器械为主，降低协调需求
- 不追求力竭，以动作质量为核心
- 恢复能力弱，同一肌群至少72小时恢复

**Tier 2（过渡）**

- 从固定器械过渡到自由重量
- 开始引入复合动作
- 同一肌群至少48小时恢复

**Tier 3（进阶）**

- 自由重量主导，大重量复合动作
- 可引入周期化训练
- 同一肌群48小时恢复，训练频率可更高

-----

## 三、目标引导与训练变量

### 意图分流

**意图明确**（检测关键词直接映射）：

- 减脂/减肥/瘦/减重 → `goal: fat_loss`
- 塑形/线条/紧实/马甲线 → `goal: toning`
- 增肌/练大/壮/力量 → `goal: muscle_gain`
- 健康/维持/活动/精力 → `goal: maintenance`

**意图模糊** → 最多两个引导问题：

**Q1：** “你希望训练之后，身体有什么变化？”

**Q2（Q1仍模糊时）：**
“你更在意镜子里看起来的变化，
还是身体能做到什么？”

- 外观 → 结合BMI判断走 `fat_loss` 或 `toning`
- 功能 → 走 `maintenance` 或 `muscle_gain`

Q2之后无论如何不再追问，直接判定。

### 各目标训练变量（NSCA处方标准）

|目标         |强度(%1RM)|次数    |组数|组间休息  |训练重心   |
|-----------|--------|------|--|------|-------|
|fat_loss   |50-70%  |15-20次|3组|30-45秒|代谢压力+心肺|
|toning     |67-80%  |12-15次|3组|60秒   |肌肉耐力+形体|
|muscle_gain|75-85%  |8-12次 |4组|90秒   |渐进超负荷  |
|maintenance|60-75%  |12-15次|3组|60秒   |全身均衡   |

### 动作顺序原则（NSCA标准，必须遵守）

1. 大肌群动作先于小肌群
1. 多关节复合动作先于单关节孤立动作
1. 高强度动作先于低强度动作
1. 上肢和下肢可交替排列减少疲劳

-----

## 四、训练频率与肌群安排

### 频率判定与分化方案

|用户频率  |分化方案        |NSCA依据   |
|------|------------|---------|
|1-2次/周|全身训练        |频率不足以支撑分化|
|3次/周  |推/拉/腿三分化    |经典三日分化   |
|4次/周  |上肢/下肢四分化    |上下肢交替    |
|5-6次/周|六分化         |高频专项训练   |
|每天    |六分化+自动安排1休息日|肌群轮换保证恢复 |

### 48/72小时恢复规则（自动执行）

- Tier 1：同一肌群间隔≥72小时
- Tier 2/3：同一肌群间隔≥48小时
- 排期生成时自动校验，用户无感知

-----

## 五、器械判定与自重过渡

### 判定逻辑

**有健身房器械** → 按Tier走完整EXERCISE_LIBRARY

**只有哑铃** → 限定 `equipment: dumbbell` 动作

**完全无器械 + Tier 1** →

- 只生成自重计划，不添加任何提示
- 打卡满8次后询问一次：
  “你已完成8次训练，想加入器械训练吗？”
  - 是 → 更新userProfile，下次含器械计划
  - 否 → 继续自重，16次后再询问

**完全无器械 + Tier 2/3** →

- 生成自重计划
- 计划末尾加一行：
  “你的训练基础适合器械训练，有条件时可以考虑。”

-----

## 六、动作禁忌与受伤史处理

### 受伤部位排除规则（NSCA禁忌动作标准）

|受伤部位|排除动作            |替代方向      |
|----|----------------|----------|
|膝盖  |深蹲、弓步、跳跃、腿屈伸    |游泳、上肢训练为主 |
|腰椎  |硬拉、早安式、仰卧起坐、过头动作|俯卧撑、卧推、腿部 |
|肩袖  |推举、侧平举、上斜卧推、引体向上|下肢、核心为主   |
|手腕  |杠铃卧推、俯卧撑、腕屈伸    |哑铃中性握、腿部  |
|颈椎  |颈后推举、颈后下拉       |所有动作改为颈前版本|

### 双入口收集机制

- **Onboarding时**：PAR-Q Q3收集
- **训练中随时**：页面固定”我有不适”入口
  点击后立即重新生成计划，排除相关动作

-----

## 七、训练后单问反馈系统

### 每次训练结束后问一个问题（轮流，不重复）

**问题池：**

1. “今天最累的动作是哪个？”
1. “完成得怎么样？比上次轻松了还是差不多？”
1. “哪个动作感觉做得最标准？”
1. “有没有哪个动作感觉不太对劲？”
1. “今天的强度合适吗？”

### 反馈处理规则（NSCA进阶判断标准）

|反馈信号        |调整动作                  |
|------------|----------------------|
|“太轻” / “太简单”|下次同部位自动升一个难度等级        |
|“太重” / “做不完”|下次同部位自动降一个难度等级        |
|某动作”感觉不对劲”  |标记，下次替换为同部位替代动作       |
|连续3次”完成很好”  |提示用户考虑升级Tier（NSCA进阶标准）|
|连续3次”太轻”    |强制触发Tier升级评估          |

-----

## 八、周期化进阶（NSCA线性周期化）

### Tier 1进阶路径（约4-6周）

```
第1-2周：动作熟悉期
  → 3组×15次，轻重量，专注动作质量
第3-4周：适应期
  → 3组×12次，适度增重
第5-6周：评估期
  → 连续3次完成→提示升级Tier 2
```

### Tier 2进阶路径（约6-8周）

```
第1-2周：过渡期
  → 3组×12次，引入自由重量
第3-5周：发展期
  → 3组×10次，渐进增重
第6-8周：评估期
  → 连续3次完成→提示升级Tier 3
```

### Tier 3维持（持续）

```
每4周调整一次训练变量：
  → 次数范围、动作选择、训练顺序轮换
  防止平台期（NSCA变化原则）
```

## 十、降级策略

DeepSeek API不可用时：

1. 直接调用 `buildLocalPlan(selectedParts, userTier)`
1. 根据 `goal` 字段覆盖组数和休息时间
1. 动作顺序自动按NSCA原则排序
1. 用户无感知，流程不中断

## 十一、安全边界（NSCA职业标准）

- **不在执业范围内的内容不涉及：**
  康复训练、疾病管理、营养处方（超出基础建议）
- **必须转介的情况：**
  PAR-Q阳性、持续疼痛、急性损伤
- **未成年用户（age < 16）：**
  只生成自重训练，不推荐负重
- **检测到医疗关键词：**
  停止生成，建议就医
